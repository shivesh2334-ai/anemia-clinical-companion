# Anemia Clinical Companion

Static clinical education and decision support application with assessment, pathophysiology, treatment, learning, and searchable knowledge bank tabs.

## Run locally

Run `python3 -m http.server 8000` and open http://localhost:8000.

## Vercel

Import this repository, choose Other as the framework, and deploy from the repository root. No build command, dependencies, or environment variables are required.

Clinical content is supplied by the original application and requires clinician verification against current local guidance.
